## 3. Критические рекомендации

### 🔴 Высокий приоритет

#### 3.1 Оптимизация i18n (372KB → ~100KB)
**Проблема**: 11 языков, но используются только RU и EN

**Решение**:
```typescript
// Удалить неиспользуемые языки из i18n/index.ts
// Оставить только:
- en (English)
- ru (Russian)

// Экономия: ~270KB (73% уменьшение)
```

#### 3.2 Code Splitting
**Проблема**: index.js 732KB (gzip: 205KB)

**Решение**:
```typescript
// Динамический импорт для тяжёлых компонентов
const Subscription = lazy(() => import('./components/Subscription'));
const Settings = lazy(() => import('./components/Settings'));
const DayDetail = lazy(() => import('./components/DayDetail'));
```

#### 3.3 Оптимизация JSON локализаций
**Проблема**: en.json (63KB), ru.json (97KB)

**Решение**:
- Удалить неиспользуемые ключи
- Разделить на чанки (landing, app, recommendations)
- Использовать lazy loading для recommendations

2. **Переключение языка** - ✅ исправлено
3. **Отсутствие кэширования** - пересчёт каждый раз
4. **SEO** - минимальная оптимизация
