## Суть

Строим не «календарь-калькулятор», а **платформу привычки**:

Пользователь → аккаунт → память → ИИ (пишет первым) → дневник → календарь → история → аналитика → подписка → возврат завтра.

**Формула → интерпретация → помощник** — правильно. ИИ объясняет, не предсказывает.
